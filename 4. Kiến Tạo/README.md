# 4. Kiến Tạo

Nơi tri thức trở thành kết quả.

- `1. Đang Làm/`: có deadline và deliverable.
- `2. Lĩnh vực/`: trách nhiệm duy trì.
- `3. Tham khảo/`: tài nguyên có thể dùng lại.
- `4. Tạm Dừng/`: đã xong hoặc đang dừng; archive, không xoá.
